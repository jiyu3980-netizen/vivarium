# 사이버 비바리움 (단면도 편집기 + 비바리움 관찰)
기존 HOUSE 탭과 별개의 독립 사이트입니다. 에셋은 `../section-assets/` 를 필요할 때만 불러옵니다(경로는 config.js).

실행: 두 폴더(`section-site`, `section-assets`)를 같은 상위 폴더에 두고, 그 상위 폴더에서 `python3 -m http.server 8000` 후
브라우저에서 `http://localhost:8000/section-site/` 를 엽니다. (GitHub Pages 등 정적 호스팅에도 그대로 올라갑니다. file:// 로 직접 열면 JSON을 못 읽습니다.)

기능: 건물 폭/층수/층고/슬래브/외벽/지붕 설정, 내벽 추가·삭제, 가구 라이브러리(검색·분류·드래그/클릭 추가, 스크롤 시에만 이미지 로드),
정면·좌측·우측 뷰 전환, 이동·크기(비율 고정)·좌우반전·복제·삭제·앞/뒤 순서, 층 바닥 자동 붙임(Alt로 해제),
되돌리기/다시 실행(120단계), 확대·이동, 이름 저장/불러오기(브라우저), JSON 파일 내보내기/열기, 자동 저장.

디자인: 레퍼런스(펜 잉크 단면도·회색 입자 도면)를 반영한 무채색 스타일. '격자', '흰 채움·그림자' 옵션 토글, 상단 제목은 직접 수정 가능.


## 4차 개선 (선 굵기 stroke · 구조 편집 · 단면 표현)
- 가구 선: 에셋 SVG 의 선(`<path d>`)과 매끄럽게 다듬은 외곽 실루엣(`*.fill.svg` 의 `path.o`)을 도면에 인라인으로 넣어 SVG stroke 굵기(cm 단위)로 그립니다. 선을 도형으로 다시 그리지 않습니다.
- 굵기 규칙: 외곽선 ≤ 가구 긴 변의 4%, 내부선 ≤ 외곽선의 절반. '자동 통일'이 켜져 있으면 15cm 이상 가구 중 가장 작은 것을 기준으로 모든 가구의 외곽선·내부선이 같은 굵기로 맞춰집니다.
- 단면 상태(가구별): 투영(기본) / 절단(굵은 선) / 벽 뒤(절단된 벽·슬래브 뒤에 가려지고 연하게). 자동 판별이 아닌 직접 지정입니다.
- 건물 탭: 층별 층고, 내벽(두께·재질·끌어서 이동), 방 이름·폭(벽 사이 자동 구성), 문·창문(내벽/외벽의 단면 개구부, 뒷벽 입면 개구부), 직선·ㄱ자·U자 계단(위층 슬래브 개구부 자동).
- 표현 탭: 외곽/내부/절단 선 굵기, 벽·슬래브·지붕 재질(기본 사선·콘크리트·벽돌·목재·단열재·철골·흰색)과 해칭 크기.
- 도면 SVG/PNG 저장. 저장 데이터는 v2 형식(옛 저장본도 그대로 열림).

## 5차 개선 (Gridsnap · Occlusia 문서 반영)
- 레벨 표시(층 높이 ±0.00 / +2.70 …), 층별 위 슬래브 두께, 계단 단 수 지정, 창 유리 한 줄·창틀/문틀 작은 단면.
- 레이어 켜기/끄기(지면·뒷벽·지붕·벽슬래브·개구부·계단·가구·방이름·레벨), 해칭 각도·선 굵기 배율, '벽 뒤' 가구의 불투명도·점선.
- 아직 없는 것: 단면선 위치·보기 깊이·크롭·방향 뒤집기, 82종 해칭 라이브러리·프리셋, 객체별 선 종류/색/투명도, DWG/PDF 내보내기.

## 6차 수정
- 제목 문구("SECTION A — 우리 집 단면도") 제거 (제목 입력칸은 비어 있음, 원하면 직접 입력)
- 미분류(검토 필요) 분류 삭제 / 야외 시설→텐트, 야외 시설 1~3→양동이 1~3 / 중복 위스키 배럴 1개 삭제
- 가구 보기 버튼: front / side 로 통일 (좌·우 버튼 → side)
- 가구 드래그: 프레임당 1회 갱신, 드래그 중 질감 필터 해제, 벽·층·다른 가구에 8px 스냅(Alt 해제)
- 가구 그림자/음영 제거
- 내벽: 위치 비우면 자동 배치, "도면에서 클릭해 벽 추가" 도구 추가
- 벽지 5종(나무·단색·꽃무늬·철제·네모 타일), 층별 선택
- 지하층(0~3) 지원
- 계단: 바닥 뒤에 그려 바닥이 끊기지 않음(개구부는 옵션), 그랜드 나선형·유리 난간 계단을 건물 탭 계단 종류로 이동
- 저장/내보내기 시 파일명 입력, 좌·우 패널 접기/펴기
- 라이브러리 썸네일(assets/thumbs) + 지연 로딩

## 7차 변경
- 상단 "파일로 내보내기"·"파일 열기" 버튼 제거. 대신 **내 단면도 (n/5)** 버튼: 로그인 없이 이 브라우저(같은 기기)에 최대 5개까지 자동 저장되고, 새로고침·재부팅 후에도 이어서 열 수 있습니다. 열기·이름 바꾸기·삭제 지원.
- 저장 위치는 브라우저 localStorage 입니다. 다른 기기·다른 브라우저·시크릿 창에서는 보이지 않고, 사이트 데이터를 지우면 사라집니다.
- 벽 안쪽 기본 배경을 흰색으로 변경(이전 저장본은 그대로 유지).
- 새 저장소 권장: `section-house-editor` (section-site, section-assets 폴더를 함께 올리고 Pages 를 main /(root) 로 설정 → `/section-site/`).

## 비바리움 관찰 1단계
- 상단에 **단면도 편집 / 비바리움 관찰** 탭 추가(주소 해시 #edit / #viv). 편집기는 그대로 동작합니다.
- 관찰 탭: 편집기에 저장된(자동 저장 슬롯, 비어 있지 않은) 단면도를 읽기 전용으로 보여 줍니다. 저장된 도면이 없으면 안내 화면이 나옵니다(가짜 샘플 없음). 집이 여러 개면 좌우 화살표·점·스와이프로 넘깁니다. 관찰은 도면 데이터를 바꾸지 않습니다(렌더 시 복제본을 사용).
- 캐릭터 등록: PNG/JPEG/WebP/GIF, 5MB 이하, 16px 이상. 가짜 확장자·SVG는 거부. 긴 변 512px로 축소(비율 유지), 투명 배경이 있으면 PNG로 그대로 유지. 이름(30자)·자유 서술 프로필(2000자), 최대 8명, 수정·삭제 가능. GIF는 첫 프레임만 사용.
- 도면 위 캐릭터: 드래그 이동(층 바닥에 붙음), 핸들 또는 숫자 입력으로 크기 조절(비율 유지). 선택하면 이름·프로필·현재 위치·현재 행동·상태 문구 표시. "외출 중"은 별도 값으로 이미지를 숨기고 문구만 표시합니다.
- 행동은 지금은 직접 고르는 임시 설정이며, 서울 시각 기반 자동 시뮬레이션은 다음 단계입니다.
- 저장소(이 브라우저 전용): localStorage `viv.chars.v1`(프로필) · `viv.place.v1`(위치·행동) · `viv.sim.v1`(시뮬레이션 상태, 현재 빈 구조) · `viv.ui.v1`, 이미지 본문은 IndexedDB `vivarium`. 도면 슬롯(`sectionSite.slots`)과 완전히 별도이며 다른 기기·브라우저와는 공유되지 않습니다.
- app.js 끝에 `window.SectionBridge`(편집기 내부 함수 일부 공개)를 추가했습니다. viv.js 가 이것만 사용합니다.

## 비바리움 관찰 2단계 — 규칙 기반 생활 시뮬레이션 (외부 AI 없음)
파일: `sim.js`(엔진, 화면·저장소와 무관한 순수 로직) · `viv.js`(말풍선·걷기·외출·선택 버튼 연결) · `viv-data.js`(저장).
- **시간**: 항상 `Asia/Seoul`(KST, UTC+09:00). 기기 시간대와 무관(뉴욕·오클랜드 시간대에서도 같은 결과로 테스트).
- **갱신 방식(복잡한 오프라인 재생 없음)**: 관찰 탭을 열 때·집을 넘길 때·화면이 켜져 있는 동안 1분마다(가벼운 시각 비교만), 각 캐릭터의 `다음 결정 시각(decideAt)`이 지났으면 "지금 서울 시각에 어울리는 행동"을 한 번만 고른다. 며칠 뒤에 들어와도 결정은 1회이며 그 시각의 행동으로 복귀한다.
- **행동 11종**: 기상·정비(양치·세수·샤워·목욕·머리 말리기·옷 고르기·화장·면도·구급상자), 식사(식탁·요리·냉장고·커피·설거지·음주), 수면(밤잠은 기상 시각까지, 낮잠은 20~60분), 휴식(소파·차·벽난로·창밖), 독서, 작업, TV, 취미, 집 가꾸기(꽃병·식물·창문·빨래·정리), 반려동물, 집 안 이동, 외출·귀가, 대화(소파·식탁·서서·연인 필로우톡).
- **시간대 → 후보**: 시간대별 기본 가중치표(예: 새벽 수면, 7~8시 기상·정비, 12·18시 식사, 오후 외출·작업, 밤 TV·독서). 올빼미형은 하루가 약 2시간 늦게, 아침형은 약 1.5시간 빠르게 움직인다.
- **프로필 해석(키워드 규칙, AI 아님)**: 상세 패널에 "프로필에 적힌 사실"(성별·나이·연인 — 자기 서술로 확실한 것만)과 "규칙 추정"(성향 19종, 찾은 단어 표시)을 구분해 보여 준다. "술은 싫어해요"처럼 부정이 붙으면 반대로 반영하고, 추정은 확률만 바꿀 뿐 같은 행동만 하게 하지 않는다. 해석이 안 되는 프로필은 기본 규칙으로 움직인다. 프로필을 고치면 **다음 결정부터** 반영된다.
- **가구 분류**: 에셋의 분류·이름·태그·원본 블록명(+에셋 ID)으로 kind를 붙인다(침대·소파·책상·식탁·책장/책·꽃병·TV·주방 시설·옷장/행거/화장대/구급상자·와인/술·욕실·가전·식물/채소·동물·악기 등). 해당 가구가 없거나 이동할 수 없는 곳이면 그 행동은 후보에서 빠진다. 창문은 도면의 창문 개체로 인식한다.
- **공간·이동**: 내벽으로 나뉜 구간(방)을 노드로, **문이 달린 내벽**과 **계단**을 통로로 하는 그래프에서 경로를 찾는다. 문 없는 벽·막힌 방은 통과하지 않고, 외출은 1층 외벽 문이 있어야 한다. 방 이름은 사용자가 붙인 이름 > 가구 추정(침실·욕실·주방·거실·서재) > 층 이름 순.
- **연인 규칙**: 프로필에 연인 표현과 상대 캐릭터 이름이 같은 문장에 있을 때만 연인으로 본다(상대 프로필에만 적혀도 인정). 같은 침대에서 잘 때 안고 자기·팔베개 같은 문구가 무작위로 나오고, 밤·아침에 필로우톡이 나온다. 연인이 아니면 한 침대를 함께 쓰지 않는다. 면도는 "20세 이상 남성"이 프로필에 명시된 경우에만, 화장은 "여성"이 명시된 경우에만 나온다.
- **말풍선·외출**: 말풍선 문구는 저장된 `say` 값 그대로라 실제 행동과 항상 일치한다. 외출 중에는 캐릭터 이미지를 숨기고 "친구를 만나러 외출했어요" 같은 문구를 도면 위쪽 안내줄에 표시한다. 눕기(수면)·앉기·서기 자세를 표시하고, 상태는 최종 위치로 저장한 뒤 화면에서만 걸어가는 모습을 보여 준다(계단은 높이도 변함, 움직임 줄이기 설정이면 생략).
- **사용자 선택**: 「집에서 책 읽기 / 식사 / 잠깐 자기 / 쉬기 / 작업 / TV / 취미 / 씻고 단장 / 산책하러 나가기 / 친구에게 연락 / 다른 캐릭터와 대화」. 가구·길·서울 시각 조건을 확인해 불가하면 이유를 보여 주고, 가능하면 즉시 반영하며 이후 약 90분간 그 방향의 가중치가 올라간다(30분 안에 반영되지 못한 선택은 사라짐). 선택하지 않아도 자율 행동은 계속된다. 직접 끌어서 옮기면 그 자리에서 5분 쉰 뒤 다시 자율 행동.
- **저장(이 브라우저 전용)**: 캐릭터당 `viv.place.v1`(집·층·x·자세·행동 그룹/세부·가구 uid·문구·외출 여부)과 `viv.sim.v1`(다음 결정 시각·결정 횟수·최근 행동·후속 행동·선택·외출 복귀 시각). 초 단위 기록·행동 이력 저장 없음. 도면 슬롯은 읽기만 한다.
- **공유 단계 대비**: 결정은 `(캐릭터 id, 결정 횟수, 서울 시각(분), 프로필, 도면)`만으로 정해지는 결정적 난수를 쓰므로 같은 입력이면 같은 결과다. 서버가 하나의 상태를 관리하게 되면 `Sim.stepHouse(ctx)`를 그대로 서버에서 돌리고 `getPlace/setPlace/getSim/setSim`만 서버 저장소로 바꾸면 된다. 사용자별로 같은 캐릭터를 따로 움직이는 구조는 만들지 않았다.
- **알려진 한계**: ① 이동은 가로 한 줄(층별)과 계단 끝점 기준이라 복잡한 계단·가구 위 이동은 근사. ② 앉기·눕기 높이는 가구 높이 비율 추정. ③ 방은 내벽 구간 단위라 한 구간에 욕실·주방이 섞이면 행동에 맞는 이름(욕실/주방/침실)을 쓴다. ④ 관찰 탭은 화면을 열어 둔 때만 15초 간격으로 갱신하고 닫아 두면 갱신하지 않는다(다시 열면 한 번 갱신). ⑤ 다른 집(슬롯)은 그 집을 열 때 갱신한다.


## 비바리움 관찰 3단계 — 초대 코드로 집 공유

- **구조**: 기본은 지금처럼 이 브라우저에 저장(백엔드 없음). 「집 공유하기」를 누르면 그 집이 서버(`section-server/worker.js`, Cloudflare Workers + D1 무료)에 **집 ID 하나**로 만들어지고, 도면·캐릭터·시뮬레이션 상태·참여자·초대 코드가 모두 그 집 ID 에 연결돼요. 도면/캐릭터를 여러 곳에 복제하지 않아요(공유 집의 캐릭터는 이 브라우저 저장소에 복사되지 않음).
- **서버 켜기**: `config.js` 의 `VIV_API` 에 서버 주소를 넣어요. 비어 있으면 공유 기능이 꺼지고 1~2단계 기능만 동작해요. 설치 방법은 `../section-server/README.md`.
- **메인 화면 「입장하기」**: 위쪽 메뉴의 「입장하기」→ 6자리 초대 코드(+선택 별명) → 서버가 검증 후 참여. 잘못된 코드/폐기된 코드/기간 지난 코드/정원 초과/요청 과다에 각각 안내가 나와요. 공개 집 목록·검색은 없어요.
- **집 공유하기**(비바리움 상단): 보고 있는 내 집을 공유 집으로 만들고 코드를 발급해요. 이 집에 둔 내 캐릭터를 함께 옮길 수 있어요(이 브라우저에서는 지워지고 서버로 이동). 공유한 집은 목록에 한 번만 나오고, 내 단면도를 고치면 비바리움을 열 때 자동으로 서버 도면에 반영돼요.
- **공유 정보/관리**: 코드 상태·복사·**새로 발급(기존 폐기)**·폐기, 참여자 목록·내보내기, 별명 변경, 도면 즉시 반영, 복구 키 복사, 집 삭제/나가기.
- **권한**: 도면·초대·참여자 관리는 집 주인만. 캐릭터 수정·삭제·이동·크기·행동 방향 선택은 등록한 사람과 집 주인만(남의 캐릭터는 보기만 가능, 화면 버튼도 꺼지고 서버도 403). 모든 검증은 서버에서 해요.
- **하나의 상태**: 공유 집 캐릭터의 위치·행동은 서버 값이 기준이에요. 각 브라우저가 서울 시각 규칙으로 계산한 결과를 서버에 올리되, 먼저 반영된 쪽이 이기고 나머지는 서버 상태를 받아 써요(참여자마다 다른 상태를 갖지 않음).
- **갱신 주기**(요청 반영): 행동 하나가 이어지는 시간을 종류별로 30~180분 안에서 랜덤으로 잡고(식사·정비는 짧게, 휴식·독서·작업·TV·취미는 길게), 화면은 1분마다 시각만 비교해요. 서버 확인은 45초마다 변경 여부만 가볍게 물어봐요.
- **의자**: 소파처럼 의자에서도 차 마시기·창밖 보기·졸기·독서·메모·TV·취미·대화(둘이 앉기는 의자마다 1명)가 나와요.
- **프로필 기반 행동**: 가구가 없어도 프로필에서 유추되는 행동(스트레칭·홈트·흥얼거리기·수첩 낙서·구절 곱씹기·할 일 정리·레시피 검색·휴대폰 영상/메시지 등)이 나오고, 프로필에 직접 적힌 「취미는 ○○ / ○○를 좋아한다」는 표현은 그대로 뽑아 문구에 써요(규칙 기반, 부정 표현 제외). 「프로필에 적힌 사실」 칩에 '좋아하는 것'으로 보여요.
- **알려진 한계**: 익명 참여자는 브라우저 토큰이라 데이터 삭제·기기 변경 시 사라질 수 있어 복구 키를 제공해요 / 시뮬레이션은 열려 있는 브라우저가 계산해 서버에 올려요 / 공유 집 도면은 집 주인 브라우저에서만 고쳐요(참여자 공동 도면 편집은 아직 없음) / 활동 이력은 저장하지 않아요.

## 비바리움 관찰 4단계 — 초대 코드 기반 공동 편집

- 공유 집은 **누구나 편집기에서 고치고 「저장 (공유)」** 할 수 있어요. 공유 집 정보 → 「편집기에서 열기」로 내 단면도 칸에 작업 사본이 만들어져요.
- 편집 탭 위쪽에 **저장됨 / 저장되지 않은 변경 사항 / 저장 중… / 저장 실패(다시 시도)** 와 현재 버전(v숫자)이 표시돼요. 저장 전의 변경은 나만 볼 수 있고, 실패하면 공유 도면은 그대로 두고 내 편집 내용을 보존해요. 저장 중에는 버튼이 잠겨 중복 저장되지 않아요.
- 다른 참여자가 먼저 저장했다면: 겹치지 않으면 자동으로 합쳐 저장하고, 같은 가구를 다르게 바꿨거나 한쪽이 지운 걸 다른 쪽이 고쳤다면 **내 쪽으로 저장 / 최신 불러오기 / 취소** 중에서 고르게 해요(내 변경은 브라우저에 백업).
- **비바리움 관찰 탭은 저장된 최신 버전만** 써요. 저장되면 관찰 화면이 새 도면으로 바뀌고, 캐릭터는 프로필·생활 기록을 그대로 둔 채 위치와 쓰던 가구만 보정돼요(지워진 가구 → 행동 취소 후 대체, 옮겨진 가구 → 따라 이동, 방 밖/없어진 층 → 가까운 방 안으로).
- 다른 참여자는 저장 알림(저장한 사람·버전·변경 요약)을 약 15초 안에 받고, 내 작업 사본이 저장된 상태면 자동으로 최신을 불러와요. 내 변경이 있으면 알림만 띄우고 「병합해서 불러오기」를 눌러야 해요.
- 캐릭터 행동은 집마다 **리더 한 브라우저**가 결정해요(서울 시각 기준). 나머지는 서버에 저장된 상태를 보여 줘요.
- 한계: 저장 전 편집은 실시간 공유가 아니에요(의도된 동작). 알림은 푸시가 아니라 약 15초 간격 확인이에요. 보관된 버전이 30개를 넘어 기준 버전이 지워지면 자동 병합 없이 선택을 물어요.

## v17 변경 — 반려동물 · 이웃하기(동네 보기·놀러가기)
**반려동물** (`sim.js`·`viv.js`, 서버 변경 없음)
- 캐릭터 등록 창의 「종류」에서 **반려동물**을 고르면 **동물 종(강아지·고양이·토끼·햄스터·새·물고기)** 과 **반려인**(같은 범위에 등록된 사람 캐릭터)을 지정해요. 등록 창과 반려동물 상세에는 「반려인 캐릭터를 먼저 등록해야 반려동물이 원활하게 움직여요」 안내가 나와요. 기본 크기는 종마다 달라요(강아지 46cm … 물고기 12cm, 이후 조절 가능).
- 종·반려인은 프로필 맨 앞 한 줄 표식 `[반려:종|반려인id]` 로 저장돼요(화면의 프로필 칸에는 보이지 않음). 그래서 공유 집에서도 같은 방식으로 동작하고 서버(worker)는 바꾸지 않았어요.
- **행동은 종마다 다르고 사람보다 훨씬 단순해요**: 종당 7~13가지(사람은 124가지). 햄스터·새·물고기는 있는 방 밖으로 나가지 않아서 계산과 저장이 더 가벼워요. 감정·관계(v16) 시스템에는 반려동물을 넣지 않아요.
- **반려인이 있을 때**: 배고픔·목마름·배변·애정(·강아지는 산책)이 '마지막으로 챙긴 시각' 5개로 저장되고(`viv.sim.v1` 의 `pet`), 나머지는 시각에서 계산해요. 필요가 쌓이면 반려인이 자율적으로 밥주기·물 갈아주기·**똥 치우기**(종별 이름: 화장실 치우기·톱밥 갈아주기·새장/어항 청소)·**산책하기**(강아지, 함께 외출했다가 같이 돌아옴)·**쓰다듬기**·**안아주기**·놀아주기·빗질을 해요. 종마다 가능한 돌봄이 달라요(물고기는 먹이·청소만, 햄스터·새는 안아주기 없음, 고양이는 산책 없음).
- **반려인이 없거나 다른 집에 있으면**: 쉬기·자기·배고파하기·반려인 기다리기만 해요(밥을 주는 사람이 없으니 점점 배고파짐).
- 「직접 행동 지정하기」: 반려인에게는 **'보리 밥주기', '보리 산책시키기'** 같은 선택지가 추가되고, 반려동물에게는 자기·쉬기·놀기·돌아다니기·밥 먹기가 나와요. 상세 패널에 상태 게이지(배고픔·목마름·배변·애정·산책)가 있어요.
- 한계: 도면 위에 똥이 그려지지는 않고 「배변: 치울 것 N개」로 표시돼요. 반려동물도 캐릭터 수 한도(8명)에 들어가요. 공유 집의 반려동물 상태 게이지는 시뮬레이션이 돌고 있는 기기 기준으로만 이어져요.

**이웃하기**
- 메인 위쪽 「입장하기」 옆의 **이웃하기**: 이웃은 **초대 코드를 등록한 집**이에요. 내가 만든 공유 집이든 입장한 공유 집이든 이웃으로 삼을 집의 코드를 모두 등록해야 해요(코드 없이 방문하는 기능은 없음). 코드는 이 기기에만 저장되고, 이 기기에 코드가 저장된 공유 집(만든 기기 또는 입장한 기기)의 코드만 등록돼요.
- 이웃이 있으면 관찰 화면 위쪽에 **동네 보기**가 생겨요. 이웃 집들을 같은 축척·땅 높이로 작은 간격을 두고 나란히 보여 주고, 건물을 누르면 그 집으로 이동해요(지금 집은 가운데). 동네 보기에서는 캐릭터를 옮기거나 지정할 수 없고 보기만 해요.
- 「직접 행동 지정하기」에 등록한 이웃 집마다 **'(집 이름) 놀러가기'** 가 생겨요(문이 있어야 하고, 서울 시각 23~5시는 불가). 놀러 간 캐릭터는 60~120분 뒤 돌아오고, 그동안 놀러 간 집 화면 오른쪽 위에 '손님'으로 보여요. 반려동물은 놀러 가지 않아요.
- 한계: 코드가 없는 집(공유하지 않은 내 도면)은 이웃이 될 수 없어요. 놀러 가는 모습은 서버로 전해지지 않아서 이 기기 화면에서만 보이고(공유 집 캐릭터가 시뮬레이션으로 외출한 사실은 기존 방식대로 같은 집 참여자에게도 보임), 새로고침해도 손님 표시는 외출 문구로 다시 찾아 보여요.

- 미구현: 이웃집에 '실제 손님'으로 머물며 그 집 캐릭터/가구와 상호작용(현재는 기존처럼 놀러 간 캐릭터가 방문자로 표시만 됨), 집 밖 외벽 가구 상호작용.

## v22 변경 — 이웃 신청
- 「이웃하기」: 우리집(내가 주인인 공유 집) 선택 + 이웃집 코드 → 이웃 신청 전송. 상대 집 주인이 수락하면 서버가 양쪽을 자동 연결하고, 양쪽 모두 서로의 집에 입장하기와 같은 권한으로 자동 입장(코드 입력 불필요). 받은 신청은 이웃하기 버튼의 ●표시·알림·창에서 수락/거절.
- 공유하지 않은 내 집은 서버 연결이 안 되어 신청에 쓸 수 없음(「집 공유하기」 먼저). 예전 방식(이 기기 저장) 연결은 그대로 유지되고 창에서 해제 가능.
- 서버(section-server/worker.js) 재배포 필요.

## v22.1 변경 — 행동 갱신 15분 눈금 · 이웃집 손님 표시
- 행동 갱신: 평소 행동은 다음 :00/:15/:30/:45 눈금(5분 미만 남으면 그다음 눈금)까지만 하고 다시 정함. 밤잠·낮잠·준비 동작·직접 지정 시간은 예외로 길게 유지.
