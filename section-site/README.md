# 단면도 집 꾸미기 (Section View Editor)
기존 HOUSE 탭과 별개의 독립 사이트입니다. 에셋은 `../section-assets/` 를 필요할 때만 불러옵니다(경로는 config.js).

실행: 두 폴더(`section-site`, `section-assets`)를 같은 상위 폴더에 두고, 그 상위 폴더에서 `python3 -m http.server 8000` 후
브라우저에서 `http://localhost:8000/section-site/` 를 엽니다. (GitHub Pages 등 정적 호스팅에도 그대로 올라갑니다. file:// 로 직접 열면 JSON을 못 읽습니다.)

기능: 건물 폭/층수/층고/슬래브/외벽/지붕 설정, 내벽 추가·삭제, 가구 라이브러리(검색·분류·드래그/클릭 추가, 스크롤 시에만 이미지 로드),
정면·좌측·우측 뷰 전환, 이동·크기(비율 고정)·좌우반전·복제·삭제·앞/뒤 순서, 층 바닥 자동 붙임(Alt로 해제),
되돌리기/다시 실행(120단계), 확대·이동, 이름 저장/불러오기(브라우저), JSON 파일 내보내기/열기, 자동 저장.

디자인: 레퍼런스(펜 잉크 단면도·회색 입자 도면)를 반영한 무채색 스타일. '격자', '흰 채움·그림자' 옵션 토글, 상단 제목은 직접 수정 가능.


## 4차 개선 (선 굵기 stroke · 구조 편집 · 단면 표현)
- 가구 선: 에셋 SVG 의 선(`<path d>`)과 매끄럽게 다듬은 외곽 실루엣(`*.fill.svg` 의 `path.o`)을 도면에 인라인으로 넣어 SVG stroke 굵기(cm 단위)로 그립니다. 선을 도형으로 다시 그리지 않습니다.
- 굵기 규칙: 외곽선 ≤ 가구 긴 변의 4%, 내부선 ≤ 외곽선의 절반. '자동 통일'이 켜져 있으면 15cm 이상 가구 중 가장 작은 것을 기준으로 모든 가구의 외곽선·내부선이 같은 굵기로 맞춰집니다.
- 단면 상태(가구별): 투영(기본) / 절단(굵은 선) / 벽 뒤(절단된 벽·슬래브 뒤에 가려지고 연하게). 자동 판별이 아닌 직접 지정입니다.
- 건물 탭: 층별 층고, 내벽(두께·재질·끌어서 이동), 방 이름·폭(벽 사이 자동 구성), 문·창문(내벽/외벽의 단면 개구부, 뒷벽 입면 개구부), 직선·ㄱ자·U자 계단(위층 슬래브 개구부 자동).
- 표현 탭: 외곽/내부/절단 선 굵기, 벽·슬래브·지붕 재질(기본 사선·콘크리트·벽돌·목재·단열재·철골·흰색)과 해칭 크기.
- 도면 SVG/PNG 저장. 저장 데이터는 v2 형식(옛 저장본도 그대로 열림).

## 5차 개선 (Gridsnap · Occlusia 문서 반영)
- 레벨 표시(층 높이 ±0.00 / +2.70 …), 층별 위 슬래브 두께, 계단 단 수 지정, 창 유리 한 줄·창틀/문틀 작은 단면.
- 레이어 켜기/끄기(지면·뒷벽·지붕·벽슬래브·개구부·계단·가구·방이름·레벨), 해칭 각도·선 굵기 배율, '벽 뒤' 가구의 불투명도·점선.
- 아직 없는 것: 단면선 위치·보기 깊이·크롭·방향 뒤집기, 82종 해칭 라이브러리·프리셋, 객체별 선 종류/색/투명도, DWG/PDF 내보내기.

## 6차 수정
- 제목 문구("SECTION A — 우리 집 단면도") 제거 (제목 입력칸은 비어 있음, 원하면 직접 입력)
- 미분류(검토 필요) 분류 삭제 / 야외 시설→텐트, 야외 시설 1~3→양동이 1~3 / 중복 위스키 배럴 1개 삭제
- 가구 보기 버튼: front / side 로 통일 (좌·우 버튼 → side)
- 가구 드래그: 프레임당 1회 갱신, 드래그 중 질감 필터 해제, 벽·층·다른 가구에 8px 스냅(Alt 해제)
- 가구 그림자/음영 제거
- 내벽: 위치 비우면 자동 배치, "도면에서 클릭해 벽 추가" 도구 추가
- 벽지 5종(나무·단색·꽃무늬·철제·네모 타일), 층별 선택
- 지하층(0~3) 지원
- 계단: 바닥 뒤에 그려 바닥이 끊기지 않음(개구부는 옵션), 그랜드 나선형·유리 난간 계단을 건물 탭 계단 종류로 이동
- 저장/내보내기 시 파일명 입력, 좌·우 패널 접기/펴기
- 라이브러리 썸네일(assets/thumbs) + 지연 로딩

## 7차 변경
- 상단 "파일로 내보내기"·"파일 열기" 버튼 제거. 대신 **내 단면도 (n/5)** 버튼: 로그인 없이 이 브라우저(같은 기기)에 최대 5개까지 자동 저장되고, 새로고침·재부팅 후에도 이어서 열 수 있습니다. 열기·이름 바꾸기·삭제 지원.
- 저장 위치는 브라우저 localStorage 입니다. 다른 기기·다른 브라우저·시크릿 창에서는 보이지 않고, 사이트 데이터를 지우면 사라집니다.
- 벽 안쪽 기본 배경을 흰색으로 변경(이전 저장본은 그대로 유지).
- 새 저장소 권장: `section-house-editor` (section-site, section-assets 폴더를 함께 올리고 Pages 를 main /(root) 로 설정 → `/section-site/`).
